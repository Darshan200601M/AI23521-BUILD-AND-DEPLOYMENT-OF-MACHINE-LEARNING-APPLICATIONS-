About The Project

Time Series-Based Stock Price Forecasting

Stock Price Prediction estimates future equity values using supervised machine learning. By utilizing multi-feature indicators—Opening price, Day High, Day Low, and Trading Volume—the model maps complex intraday dynamics to the eventual Close price.

Designed as part of AI23521: Build and Deploy for Machine Learning Application, this tool provides a complete end-to-end pipeline from time-series preprocessing and train-test evaluation to cloud-ready web deployment.
